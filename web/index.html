Beacon scores each story cluster from observable behavior: novelty, velocity, independent source breadth, rank movement, persistence, engagement change, and source-type diversity.

NoveltyHow different this cluster is from recent snapshots.
VelocityHow quickly mentions and independent sources are increasing.
BreadthHow many distinct sources are covering the same event.

PersistenceWhether a signal survives across repeated snapshots.
